## 1. Facts from Shopify (read only, 2026-09-28, through the Shopify connector; nothing changed)

### 1.1 Shopify's live type list (`metafieldDefinitionTypes`)

- **118 types.** 63 base kinds. 55 base kinds also exist as `list.<kind>`. These 8 have **no list form**: `boolean`, `id`,
  `json`, `language`, `money`, `multi_line_text_field`, `rich_text_field`, `product_taxonomy_disclosure_reference`.
- **32 measurement kinds** (each with a list form): `antenna_gain`, `area`, `battery_charge_capacity`,
  `battery_energy_capacity`, `capacitance`, `concentration`, `data_storage_capacity`, `data_transfer_rate`, `dimension`,
  `display_density`, `distance`, `duration`, `electric_current`, `electrical_resistance`, `energy`, `frequency`,
  `illuminance`, `inductance`, `luminous_flux`, `mass_flow_rate`, `power`, `pressure`, `resolution`, `rotational_speed`,
  `sound_level`, `speed`, `temperature`, `thermal_power`, `voltage`, `volume`, `volumetric_flow_rate`, `weight`.
  Every one of them is in Nexus's unit table (`P/shopify-field-codecs.ts:4-26`); the table has no extra kind.
- **Other kinds:** text (`single_line_text_field`, `multi_line_text_field`, `rich_text_field`), numbers (`number_integer`,
  `number_decimal`), `boolean`, `color`, `date`, `date_time`, `url`, `link`, `money`, `rating`, `json`, `id`, `language`,
  `jurisdiction`, and references: `product`, `variant`, `collection`, `page`, `article`, `file`, `customer`, `company`,
  `order`, `metaobject`, `mixed`, `disclosure`, `product_taxonomy_value`, `product_taxonomy_disclosure` (`*_reference`).
- **Validations Shopify supports** (per type, from the same read): `min`, `max`, `regex`, `choices` (text); `min`, `max`,
  `max_precision` (numbers); `min`, `max` (dates, measurements); `scale_min`, `scale_max` (rating); `allowed_domains`
  (url, link); `schema` (json); `file_type_options` (file); `metaobject_definition_id`, `metaobject_definition_type`
  (entry); `metaobject_definition_ids`, `metaobject_definition_types` (mixed, disclosure);
  `product_taxonomy_attribute_handle` (taxonomy value); `list.min`, `list.max` (every list).
- **Formats Shopify documents** (shopify.dev "List of data types" and "List of validation options", read 2026-09-28):
  measurement values use long lower-case units (`{"value": 2.5, "unit": "kilograms"}`), but measurement **limits** use
  short units (`{"unit":"g","value":10}`); `date_time` values and limits have **no time zone** (`2024-01-01T12:30:00`);
  `rating` is `{"value":"3.5","scale_min":"1.0","scale_max":"5.0"}` (strings); `file_type_options` values are only
  `Image` and `Video` (empty = every file); `choices` holds at most 128 values; `regex` is **RE2**, not JavaScript.

### 2.4 The rules (validation)

- One shared function for the pop-up, the draft save, the sheet readiness and publish:
  `validateShopifyField` (`P/shopify-linked-products.ts:188-252`), with `shopifyJsonSchemaError` and
  `shopifyObjectBoundError` (`P/shopify-definition-validation.ts:7-43`) and `shopifyReferenceError`

- **Gaps:**
  - `product_taxonomy_attribute_handle` is never checked (no code reads it; `git grep` 2026-09-28).
  - Measurement limits convert units only for `dimension`, `weight`, `volume` (`P/shopify-definition-validation.ts:23-27`);

## 4. Rules that hold for every type

1. **Open:** the sheet's usual open gestures (the editor-open ruling that `scripts/check-editor-open.mjs` checks). The pop-up
   opens under the cell (desktop) or as a sheet across the screen (< 640 px, `S/ShopifyDraftCell.tsx:58`). Focus goes to the first control. Screen readers hear "<Field>: <SKU>" (`S/ShopifyDraftCell.tsx:127, 184`).
2. **Save:** Enter (or Ctrl/⌘+Enter in a multi-line box), or a click outside. **Cancel:** Esc. Open and close with no change
   writes nothing (`:171`).
3. **Refused:** the pop-up stays open. One line in a red banner: `Not saved: <one sentence from §5>`. The sentence says what
   is wrong and what to do. A click outside is held back while the value is refused (`:98`).
4. **Read-only:** the control is shown disabled and the reason is on screen (never a silent disabled control, Q2).
5. **Footer:** cells: "Saves in Nexus · Publish to send it to Shopify". Entry editor: "Saves to Shopify now".
6. **Rules on screen:** in plain words under the control, e.g. "Up to 10 values · each up to 100 characters", replacing the raw
   `list.max` table (G6).
7. **Conflict:** someone saved the cell while it was open → "Not saved: the cell changed while this editor was open. Reopen it
   to review both values." (kept, `:177`). Shopify changed the value → "Shopify changed this value since it was read…"
   (kept, `A/channel-sheet.service.ts:111`).
8. **Unknown future type:** read-only with "The <type> type needs a Nexus value adapter. Its existing data is preserved…"
   (kept, `P/shopify-field-codecs.ts:35`). Never a crash.
9. **Publish:** review lists each change as "<product / variant> · <field>: <old> → <new>"; Shopify's refusal comes back as
   "Shopify did not save <Field> on <product>: <Shopify's message>" (new, G9).
