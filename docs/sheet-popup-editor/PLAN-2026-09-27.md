## Summary

- **What.** Rebuild two cell pop-ups on the product sheet: the **Variation theme** pop-up and the **Shopify metafield**
  pop-ups. Both show pictures next to the words, and both work like the pop-ups in Shopify's bulk editor.
- **Why.** Today the variation theme pop-up shows only axis names and a count ("Color · 2 values"). It shows no values
  and no photos. The Shopify pop-up is a small dialog. Its picker is text only, and metaobject entries have no picture.
- **How.** One shared pop-up shell and four new design-system pieces (§4.1). Then the Shopify pop-ups (§4.3), then the
  variation theme pop-up (§4.2).
- **Order.** P0 design-system pieces → P1 Shopify → P2 variation theme (Shared) → P3 variation theme (channels). Each
  phase is its own small PR.
- **Two decisions for the Owner** (§8): D1 how much the variation theme pop-up may change; D2 whether the Shopify
  pop-up may write entries straight to Shopify.

Measured in the Xavia Racing store's bulk editor on two products (MOSS Jacket, Custom Mx Suit). I opened cells and

| Field type | What the Shopify pop-up does |
|---|---|
| Category metafield, list of metaobjects (Color) | Opens under the cell. Search box "Add color". Checkbox rows, each with a **colour swatch** and the name. Two groups: the store's own entries, then "Default entries". Footer "Add new entry". Picks many. |
| List of metaobjects with an image field (Text with icon) | Top: the chosen entries as **chips with a small picture and ×**, and a search line. Below: checkbox rows with the entry's **picture**. "Add new entry". "Clear". |

| List of products (Variation products) | Chips with the product photo in the cell. The pop-up is an **ordered list**: drag handle, photo, name, ×. "Clear all". "Select products" opens a picker dialog: search, filter, rows with checkbox + photo + title, "3 products selected", Cancel / Done. |
| Plain text (Variation value) | Typed straight in the cell. |

Shopify's product page, Variants card (also read only): each option is a row with a drag handle, its name and its
values as chips; "Add another option"; below it every variant with a photo slot, price and stock.

- The server sends `valueGaps`; the web never shows them (`variation-rules.service.ts:757`, `renderers/variationTheme.tsx`).
- The Shared save writes only `Product.variationAxes` (labels) through `PATCH /studio/variation-axes`

  (`setFamilyAxes` / `setFamilyVariationValues`) has no route yet; that is VTR step 1c.

### 3.2 Shopify metafield pop-up (`_studio/shopify/ShopifyDraftCell.tsx` → `LinkedFieldEditor.tsx`)
- A small DS `Modal` (440 px) with Cancel / "Save draft". It saves a **Nexus draft**, not a Shopify write
  (`channel-sheet.service.ts:61-157`).
- References: a list with a 48 px picture only when `/reference-names` returns one (products, files). "Choose reference"
  opens a second modal, `ReferencePicker`, which is **text only** and picks **one** item per opening.
- Metaobjects, variants and collections have **no picture**: the API never asks Shopify for the metaobject's
  `thumbnailField` (`linked-products-gateway.ts:164, 189-194`).
- Colour is a plain text box. No swatch, no picker.
- No cache: every sheet load and every pop-up opening calls Shopify for names and pictures.
- "Edit entry" / "Make a separate copy" write **straight to Shopify** (`linked-metaobjects.service.ts:19-30`).

## 4. The design

### 4.1 One pop-up shell (all editors below)
Same rules as the approved Option A text editor:
- Opens **under** the cell, pinned to it. The cell and its row stay in view. On a phone it becomes a centred sheet.
- **No Save / Cancel buttons.** Enter or a click outside saves. Esc throws away. One key line at the bottom.
- Opening and closing without a change writes nothing.
- A new size kind `media` in `editorBox.ts`: up to 480 × 520. Lists scroll inside; the box never scrolls sideways.
- Pictures: 32 px in list rows, 20 px in chips, a colour swatch for colour values. **No empty picture slot** when
  there is no picture (rule UI.5, `docs/2026-09-21-product-sheet-ui-plan.md:221-225`).
- Keyboard: type to search, ↑ ↓ move, Space ticks, Backspace removes the last chip, Alt + ↑ ↓ moves a chip or row.
- Everything that pops out inside it stays inside AG's pop-up layer (`portalTo` / `ag-custom-component-popup`).
  Otherwise a click in it counts as "outside" and closes the editor.

New design-system pieces (web + `apps/factory` mirror, catalog entry, CHANGELOG line, DS-GAPS line):

| Piece | What it is | Used by |
|---|---|---|
| `MediaChipField` | Chips with picture + × and drag order, plus a search line | metaobject lists, variation values |
| `MediaPickList` | Search + checkbox rows with picture or swatch, optional groups, "Add new" footer | metaobjects, axis values |
| `MediaOrderedList` | Rows: drag handle, picture, name, × ; "Clear all" | product / variant / collection / file lists |
| `ResourcePickerDialog` | Search, rows with checkbox + picture + title, "N selected", Cancel / Done | "Select products / files" |

They reuse `Thumbnail`, `OrderedList`, `Listbox` (`leading` slot), `Checkbox`, `TokenChip`, `SearchField`.

### 4.2 Variation theme pop-up (parent row)

```
┌ Variation theme · Shared ─────────────────── 20 variants ┐
│ ⠿ Colour   [▣ Nero ×] [▣ Giallo ×]  + value              │
│ ⠿ Size     [XS ×] [S ×] [M ×] [L ×] … [5XL ×]  + value   │
│ + Add option                                              │
│ Variants ─────────────────────────────── [search]         │
│ [photo] Nero · XS     GALE-JACKET-BLACK-MEN-XS            │
│ [photo] Nero · S      GALE-JACKET-BLACK-MEN-S             │
│ …                                                         │
│ Enter saves · Esc cancels                                 │
└───────────────────────────────────────────────────────────┘
```

- Built like Shopify's Variants card: one row per option (axis) with a drag handle, its values as chips.
- A value chip shows a photo: the media-plan photo or swatch for that value when the family is on the plan, else the
  main photo of the first variant with that value. No photo → no picture slot.
- Below: every variant with its photo, its values and its SKU (read only in the pop-up).
- Actions: reorder axes; add an axis (search the dictionary, suggested ones first); remove an axis — **refused** while
  variants still carry its values, with the reason; reorder values; add a value from the dictionary options; remove a
  value — refused while a variant uses it.
- Not in the pop-up (stays in VTR's docked panel, step 2): rename / merge / archive values, labels per language,
  "Generate missing variants", per-market setups.
- Data: `GET /studio/family` already returns each child's photo, its values, each axis's values with counts and the
  value order (`family-projection.service.ts:126-176, 695-709`). No new read route.
- Save: see D1.
- Channel scopes (P3): the same shell. Each axis row keeps today's channel controls (included, target aspect /
  attribute) and shows the channel's value labels as chips.

### 4.3 Shopify metafield pop-ups (Shopify scope)

| Type | New pop-up |
|---|---|
| One metaobject | Card: picture, name, type · **Change** · **Clear**. Change opens `MediaPickList` in the same box. |
| List of metaobjects (incl. category Color) | `MediaChipField` on top, `MediaPickList` below (swatch or picture per entry), "Add new entry" (D2), "Clear". |
| Product / variant / collection (one or list) | `MediaOrderedList` with photos; "Select products" opens `ResourcePickerDialog` (picks many). |
| File (one or list) | Picture list; "Select files" opens `ResourcePickerDialog` over the store's files. Upload is not in this plan. |
| Colour | Swatch + hex box + colour picker. |
| Text, number, URL, date, true/false, measurement, money, rating | Today's editors, moved into the new shell (under the cell, no dialog). |
| Rich text, JSON | Today's text box, in the new shell. A rich-text toolbar is not in this plan. |

The save stays a **Nexus draft** (as today); Publish sends it.

API changes (all behind the channel gateway, hard rule 4):
- Read each metaobject's `thumbnailField` (colour hex or file picture) in `/references`, `/reference-names` and `/entry`.
- `/reference-names` also returns pictures for variants and collections.
- A short server cache (per store, 10 minutes, cleared on any write) for names and pictures, so a sheet load does not
  call Shopify every time.
- Shopify's "Default entries" (standard category entries not yet in the store): **first version shows store entries
  only**; standard entries come after, because picking one creates it in the store.

## 8. Decisions for the Owner

**D1 — How much the variation theme pop-up may change.**
- (a) Axes **and values**: reorder, add, remove (with the refusals above), value order. To save values, this lane adds
  one route onto VTR's existing one writer (`setFamilyAxes` / `setFamilyVariationValues`), agreed with VTR first.
  **Recommended** — it is what "rearrange like chips, add or remove" asks for.
- (b) Axes only. Values and photos are shown but read only until VTR step 1c lands.

**D2 — Shopify "Add new entry" and "Edit entry" in the pop-up.** These write straight to the Shopify store, not a draft.
- (a) Keep them (Shopify has them), with a plain "Saves to Shopify now" line and a confirm. They work only when Shopify
  publishing is on, as today. **Recommended.**
- (b) Leave them out of the sheet pop-up. They stay in the Shopify workspace only.
