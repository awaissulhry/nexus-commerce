  **creates a new duplicate parent product**, and its Shared name is the **German** title (s08; `catalog-amazon-workbook.ts:129`).
  MISANO IT's second parent `MISANO-JACKET` → 6 new products, Shared name Italian (correct language here, but a new family).
- 60 PANTS cells (`batteries_required/included`, `supplier_declared_dg_hz_regulation`) → "no unambiguous destination in the current
  schema" (AIREON, all 4 markets) — cause not yet found (stale PANTS schema or two candidate fields; to investigate).

Language, measured: DE/FR/ES values are written to that market's listing, in that market's language (the content writer
stores them in `ChannelListingTranslation.attributes` for `de`/`fr`/`es`) — never as Shared Italian — EXCEPT the Shared `name` of a
NEW product (above). Localized labels are translated back to codes by the template's own dictionary: `FORMATO/COLORE` → `SIZE/COLOR`,
`Maschio` → `male`, `Impermeabile` → `waterproof` (s01 outcomes).
