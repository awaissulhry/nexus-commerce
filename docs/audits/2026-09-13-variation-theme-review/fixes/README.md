**Variation Theme fixes — 13 September 2026**

The implementation defects identified in the original review have been repaired and verified locally. This is a code and local behavior sign-off, not a claim of marketplace acceptance or complete WCAG certification. Changes remain in the working tree; no deployment or marketplace publication was performed.

**What changed**

- The Information sheet, projection editor, rule simulation and applicable publishers consume the same effective axes, bindings and theme. Category inheritance now uses the existing taxonomy resolver, including explicit listing assignments and aliases. Rules apply their ordered mappings instead of merely changing the source label. Schema caches are scoped by workspace.
- eBay overrides store the complete set, order and names on the addressed listing. Editing Italy no longer changes the shared product theme or Germany. Reset explicitly returns to inheritance. Empty overrides and omitted axes remain distinct from inherited mappings.
- Every mapping change, including reset, validates its proposed result. Live restrictions compare names and themes as well as axes. Invalid themes, unavailable schema targets, unbound attributes, duplicate target names, collisions and oversized Shopify option names are refused. Concurrent saves use an atomic version predicate; a PostgreSQL two-writer test permits exactly one winner and returns a version conflict to the other.
- Shopify content documents receive current option membership, names and order even after initialization. Stable family keys preserve values and assignments. Published product options and variant option names use the projected display names. The content editor directs option editing to Information → Variation Theme.
- Amazon checks the entire family before its first parent or child write. Unknown/deprecated themes, unsupported bindings and duplicate child combinations stop publication. Parent and children carry the matching variation envelope. Wizard validation, composition and live-change plans use the effective selection; plans retain reset intent and remain explicitly dry runs.
- Rule impact counts use actual included variant tuples and the applicable listing/category cohort. Reads use one consistent database snapshot. Omitting an axis is no longer automatically counted as a collision. The editor clears stale collision results on a changed draft and displays “not evaluated” when no result exists.
- Etsy choices use cached taxonomy property codes. Its editor explicitly says that these are Nexus drafts and that Etsy variation-property publishing is not available yet. Missing taxonomy properties are shown as unavailable, not as a successful configuration.
- The shared editor fits narrow viewports, responds to resizing while open and wraps instructions without horizontal overflow. Strong semantic text tokens replace low-contrast instructional text. “Use inherited axes” avoids promising that a stored rule exists. Factory includes the shared editor, renderer and required dependencies; exports, catalog, changelog and DS gap records were updated. Guards now require the mirrors and recognize Factory’s grid engine boundary.

**Remaining facts that must not be represented as success**

1. GALE-JACKET’s Amazon IT and DE values contain **four colliding variants in two combinations**. The black XS and XXS records both currently resolve to Nero/XS; the yellow pair both resolve to Giallo/XS. The resolver now reports four instead of zero. Correct values need an authoritative catalog source; SKU text alone is not sufficient evidence to rewrite them.
2. Etsy’s GALE taxonomy properties are unavailable in the current cached context. The editor names that state. Etsy variation publishing is not implemented, so saving a draft cannot be called delivered.
3. Live structural theme changes still use the existing held plan workflow. A preview describes the proposed operation; it does not claim that a new Amazon parent, eBay relist or Shopify live change has occurred.
4. Provider acceptance was not exercised. Cached schema checks and payload tests prove local validation and composition, not that a marketplace accepted a publication. A Shopify sheet read also took about 15 seconds when provider enrichment was cold; a cached projection read was about 0.3 seconds. This existing enrichment path remains a performance limitation outside the Variation Theme editor itself.

Amazon’s parent/child variation envelope follows its [listing workflow documentation](https://developer-docs.amazon.com/sp-api/lang-de_DE/docs/building-listings-management-workflows-guide). Shopify’s buyer-facing option name is carried in [VariantOptionValueInput.optionName](https://shopify.dev/docs/api/admin-graphql/2026-07/input-objects/VariantOptionValueInput); the existing `productSet` operation validated against the official schema. Contrast measurements use [W3C’s enhanced text contrast criterion](https://www.w3.org/WAI/WCAG22/Understanding/contrast-enhanced).
