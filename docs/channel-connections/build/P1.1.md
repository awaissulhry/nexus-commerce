## 2. Decisions inside the build

1. **Nothing sent ⇒ thrown; a channel error ⇒ returned.** A refusal (`refused`, `held`, `gated`, `would_send`) throws `GatewayRefusal` after its ledger row. A channel's error answer comes back `ok: false` with its verdict, so each caller keeps its own error handling while it moves onto the gateway (P1.2).
2. **Retries.** A 429 (or Shopify THROTTLED inside a 200) waits for its Retry-After and retries, 2 times by default. A read is retried once on a network error / timeout / 5xx. **A write is never retried on a 5xx or a network error** — the channel may have applied it; the queue decides with the idempotency key.
3. **Publish mode applies to writes only.** Reads ignore it (a dry run still needs to read). Ads: the gateway honours only its sandbox switch (`NEXUS_AMAZON_ADS_MODE`, exact `live` else sandbox — the same rule as `ads-api-client.ts`); Ads keeps its own write gate (allowlist, caps). Shopify has no sandbox host: a sandbox Shopify write is refused (`NO_SANDBOX_HOST`), never sent live. A client moved onto the gateway "as is" may set `modeAppliedByCaller` so the mode is not applied twice.
4. **eBay language comes from the database, not a table in code.** The first build had a market→language table. The LX.2 guard (`services/pim/market-languages-guard.vitest.test.ts`) failed on it: `Marketplace.languages` is the only language authority. Now `ebayMarketHeaders(market, contentLanguage?)` reads the eBay Marketplace row: `marketplaceId` (`EBAY_IT`) + the ordered `languages` (first = default, or the caller names one of them) → `languageTag()` with a hyphen (`it-IT`, `en-GB`). A **write** to a market with no row, no languages, or a language the market does not have is refused (`MARKET_UNCONFIGURED`, 0 calls). A **read** goes without the language headers.
5. **Rate bucket fails open.** A Redis error never blocks a call (the same rule as the clustered cron). No token within `maxRateWaitMs` (30 s default) ⇒ refused `RATE_LIMITED_LOCAL` (429), 0 calls, so a queue retries later.
6. **The ledger keeps bodies only on failure**, made safe by `redact.ts`. The endpoint is stored without its query string.

## 3. Proof

- `services/gateway/gateway.p11.vitest.test.ts` — **40 tests**, fake channel that records every request (so "0 calls" is counted): each refusal step with 0 calls; dry-run `would_send`; sandbox host per channel; reads ignore the mode; push lock and wrong-account refusals; login header per channel; eBay signing only on must-sign paths; **every configured eBay market (IT, DE, FR, ES, UK/GB) plus a two-language market (BE fr / nl) sends the right three headers**; unconfigured market refused; 429 retry with attempts; THROTTLED in a 200 retried with body headroom; GraphQL errors in a 200 are not ok; local rate refusal; bucket refill and Amazon limit header; idempotency key on the row; payloads only on failure with no personal data or secret; write not retried on 5xx; read retried on network error; timeout class; 10 classification cases; redaction and cap.
- `services/gateway/gateway.ledger.p11.vitest.test.ts` — **3 tests on a real disposable PostgreSQL** (generated schema + real profile policies), rows read back from the table: a sent call has account, operation, method, endpoint, status, latency, time, `rateLimitRemaining`/`Limit` (1950 / 2000), attempts, `apiVersion`, profile id, no body; a held call writes `outcome = held` and never calls the channel; a failed call keeps its class and a safe body.
- **Mutation checks — 20, all caught**: no account check, no dry-run, write retried on 5xx, sign everything, GraphQL errors ignored, raw payload stored, push lock removed, market headers removed, THROTTLED ignored, sandbox URL not used, local rate check removed, personal fields kept, chosen language ignored, underscore tag, foreign language allowed, unconfigured write sent; ledger writer: headroom dropped, payload kept on success, outcome dropped (+ one earlier language-table mutation, now replaced). Every file compared byte-equal after restore.
- **Shared bucket on a real Redis** (a throwaway `redis:7-alpine` container, removed after; not the shared dev Redis): 10 tokens taken; a second client (another "replica") finds the bucket empty, wait 192 ms (5/s); a refill after 450 ms gives a token; a Retry-After of 3 s holds it (wait 2999 ms); Amazon limit 0.5/s stored as the refill; keys expire (1 h).
- Full API suite: **9623 passed, 6 failed** (the two known Amazon local-account files). `tsc` 0 errors.
- Guards: schema drift, column drift, model ownership, policy/migration parity, route-prisma ratchet, context boundary, cron clustered, event contract, MAP.0 connection ratchet, market languages (script + test) — all pass.
