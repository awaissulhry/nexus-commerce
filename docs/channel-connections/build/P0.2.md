## 2. Changes

1. `lib/auth/permissions-manifest.ts` — the two PUBLIC entries become `RW(F.adminView, F.jobsManage, …)` for `/api/monitoring` and `/monitoring`: reading needs admin view, changing needs jobs manage. Same rule as `/api/job-monitor`.
2. `lib/auth/internal-token.ts` (new) — `internalTokenMatches(header, secret)`: SHA-256 both sides, then `timingSafeEqual` (fixed length, never throws, never leaks the length). Fails closed on an unset/empty secret or a missing, empty or repeated header. `routes/advertising.routes.ts` uses it for the bidding-engine routes.
3. `routes/cloudinary-webhook.routes.ts` — `registerRawJsonParser` (scoped to this plugin, as in the Shopify, Sendcloud and eBay receivers) and verify the raw bytes. No raw body = refused.
