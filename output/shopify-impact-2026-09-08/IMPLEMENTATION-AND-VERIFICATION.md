## Implemented locally

- One canonical family and all native sellable child combinations in Shopify publication, with independent SKU, price and stock. New publication defaults to a Shopify draft; active-destination changes require a fresh review. The previous single-variant wizard and single-axis image publisher no longer silently publish incomplete families.
- Nexus editing of ordered reusable image groups, featured images, translated descriptive alt text, supported metafield definitions and reusable metaobject entries. Family, option, combination and exact-variant assignments have explicit inheritance, overrides, clearing, priority and conflict reporting. Variant previews show resolved content and its source.
- Account-scoped saving with revision checks; Shopify definitions, files, media, native variants, inventory, metafields, metaobjects and translation publication with remote readback. Stock writes compare observed quantities. Partial publication is marked unverified and retains checkpoints. Native offer synchronization and managed webhook routing use exact identities.
- Separate collection cards for configured option groups or variants, independently positioned in Nexus and synchronized to the collection. Global ordering/pagination includes cards across native product pages. Price/title sorting and native filtered variant matching are respected.
- Impact gallery and custom content updates use the same native variant response. Gallery groups use explicit media IDs, not alt-text conventions. Pending/failed selections cannot submit stale cart variants; older responses cannot overwrite a newer selection.
- Existing layout/settings/custom content sections retained. Old desktop hover thumbnail styling and sticky gallery CSS restored from the earlier export. Card thumbnail selections replace price, availability, images and quick-buy together. The mobile navigation hides and disables interaction with the observed Inbox, Loloyal/CWILL and Klaviyo widget hosts until it closes.

Implementation details and operating instructions: `integrations/shopify/impact/README.md` in the repository.

## Comparison of the two supplied themes

The updated export is Impact 7.2.0 (218 files). The previous customized export is Impact 6.11.2 (216 files). All previous filenames exist in the updated theme; 7.2.0 adds cart and product disclosure snippets. Of the JSON templates, only product.json differs semantically. Variant-picker and option-value changes between the exports are formatting; the image selector and size dropdown are retained native capabilities.

The old theme.css tail contains the missing desktop gallery and hover-strip customizations. Its explicit coarse-pointer rules disable thumbnail reveal on touch devices. The old layout's long-press code consequently had no visible effect under those rules. The old click handler altered only images and links, and is replaced with a complete native-card response to keep prices and cart destinations consistent. The 7.2.0 improvements to preload links and screen-reader announcements remain intact. No claim is made that every difference between two upstream Impact releases is a merchant customization.
