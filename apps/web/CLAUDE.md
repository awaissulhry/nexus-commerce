# apps/web

Next.js 16 App Router. `@/*` resolves to `src/*`. Read `/DESIGN.md` (repo root) before UI work;
its rules apply to all UI here.

## Design system — mandatory for new or edited UI
- Lives in `src/design-system/`: `primitives/` (Button, Input, Checkbox…), `components/` (Field, Modal, Listbox,
  Banner…), `patterns/`, `grid/`. The live catalog is the `/design-system` page. Read a component's `.tsx` before
  you use it; the committed `.d.ts` files can be stale.
- Import from the area barrels: `@/design-system/primitives`, `/components`, `/patterns`, `/grid`. There is no
  `@/design-system` root barrel.
- `src/components/ui` is the legacy kit. Never use it in new code.
- Compose existing primitives, components and patterns first. Missing a control or pattern? Add it to the DS,
  export it from its barrel, add a catalog entry and a `CHANGELOG.md` line, use it from the feature, and append the
  gap to `.claude/DS-GAPS.md` (append-only). A DS file that is identical in `apps/factory/src/design-system` must
  stay identical: copy the change there too, without overwriting unrelated edits.
- CSS: feature CSS holds layout and domain content only; never restyle a shared control locally. Semantic `--nds-*`
  tokens only; no raw hex, no numbered ramps. `styles/tokens.css` and `styles/tokens-global.css` are generated by
  `npm run tokens:gen`.
- **A product-studio tab surface owns its scroll:** its root gets `flex: 1; min-height: 0; overflow-y: auto`. The
  studio's `.tabPanel` is a fixed-height flex box, so a surface without its own scroll area is cut off and the wheel
  does nothing (the Media page, 2026-09-27). Put anything shown above a tab (a banner, a preview) INSIDE that scroll
  area, never beside it. `.tabPanel` scrolls as a safety net only. The root also sets `font-size:
  var(--nds-font-size-base)`: plain text otherwise shows at the browser's 16 px, and the Owner reads it as Arial. Guard:
  `src/app/products/[id]/edit/_studio/images/plan-page/planPage.scroll.vitest.test.ts`.
- Tailwind: allowed only inside legacy pages that are not migrated yet, and never as a new usage. A section at 0 in
  `scripts/ds-conformance-baseline.json` is migrated. Guards: `node scripts/check-raw-primitives-ratchet.mjs --check`
  and `node scripts/ds-conformance-guard.mjs --check`. They count colour and type classes, not layout utilities, but
  the rule covers all Tailwind.

## Exemplars
- **AG Grid Enterprise:** `src/app/settings/channels/ChannelEventsGrid.tsx` (`NexusGrid` from `@/design-system/grid`).
  - Import `ag-grid-*` only inside `src/design-system/grid/` (`scripts/check-ag-grid-import-boundary.mjs`).
  - A grid feature needs its module in `src/design-system/grid/modules.ts`, or it silently does nothing in
    production (`npm run grid:modules`).
  - A custom cell editor must call `props.onValueChange`; a ref `getValue` is never read. See
    `src/design-system/grid/editors/SelectPanelEditor.tsx`.
- **Forms:** `src/app/settings/sharing/OfferShareModal.tsx` — DS `Modal` + `Field` + controlled state.
  react-hook-form and zod appear only in the legacy `src/app/catalog/[id]/edit/` (`ProductEditorForm.tsx`). No
  design-system form uses them.
- **Charts (recharts):** `src/design-system/components/PerformanceGraph.tsx`, used by
  `src/app/marketing/ads/ebay/_dash/TrendCard.tsx`. Recharts takes colours as props: use `chart` from
  `src/design-system/tokens/colors.ts`, not `var(--nds-*)`.

## Calling the API
- Use ``fetch(`${getBackendUrl()}/api/...`)`` with `getBackendUrl` from `@/lib/backend-url`. Never hard-code a host.
  The legacy `src/app/api/*` routes point at `localhost:3001`; don't copy them.
- With `NEXT_PUBLIC_WORKSPACES_ENABLED=1`, the browser base is `<origin>/backend`, so calls go to `/backend/api/…`.
  `src/app/backend/[...path]/route.ts` forwards them to `NEXUS_API_PROXY_TARGET`. With the flag off, the browser
  calls `NEXT_PUBLIC_API_URL` directly.
- **`/backend/api/*` is a Vercel external rewrite, not a function** (`next.config.js` → `src/lib/workspaces/backendRewrite.cjs`).
  On 2026-09-27 Vercel paused the site: the `/backend` route handler (a Node function) carried every API call and every
  live stream, and the Hobby team used 331% of its Fluid Provisioned Memory. Keep long-lived work (streams, polling,
  proxies) off Vercel functions: call the API through `getBackendUrl()`. The route handler serves only
  `/backend/api/cx/*` (it fixes that cookie's path); `src/proxy.ts` skips `/backend`. A rewrite is cut after 120 s;
  `EventSource` reconnects by itself.
- `src/lib/auth/install-fetch.ts` patches the browser `fetch`. It adds credentials, `x-nexus-csrf` on writes, and
  `x-nexus-workspace-id` from the `/w/<id>` URL. Never add these by hand.
- Navigate with `Link` from `@/lib/workspaces/Link` and `useRouter`/`usePathname` from
  `@/lib/workspaces/navigation`. They keep the `/w/<id>` prefix; `next/link` drops it.
- Some server code imports `@nexus/database` directly. It gets its workspace from the resolver registered in
  `src/lib/workspaces/server.ts`.

## Tests
- Vitest collects only `src/**/*.vitest.test.ts`. The environment is Node with no jsdom: test logic, not rendering.
- Playwright specs are in `tests/`, and no webServer is configured. Most specs are `fixme` or target production.
  `pressable-row` runs against `/design-system` without a login.
- If you use `t()`, the key must exist in both `src/lib/i18n/messages/en.json` and `it.json`
  (`node scripts/check-i18n-catalog.mjs`).
