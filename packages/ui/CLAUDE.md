# packages/ui (`@nexus/ui`)

The Nexus design system: TypeScript source, compiled by the app that uses it (`transpilePackages` in
`apps/web/next.config.js`). It moved here from `apps/web/src/design-system` on 2026-10-28. The web still imports it as
`@/design-system/*` (`apps/web/tsconfig.json` paths, `apps/web/vitest.config.ts` alias). Read `/DESIGN.md` (repo root)
before UI work; its rules apply here.

## Design system — mandatory for new or edited UI
- `src/` holds `primitives/` (Button, Input, Checkbox…), `components/` (Field, Modal, Listbox, Banner…), `patterns/`,
  `grid/`, `tokens/`, `styles/`. The live catalog is the web's `/design-system` page; its examples live with the page
  (`apps/web/src/app/design-system/_catalog/`). Read a component's `.tsx` before you use it; the committed `.d.ts`
  files can be stale.
- Consumers import from the area barrels: `@/design-system/primitives`, `/components`, `/patterns`, `/grid`. There is
  no root barrel.
- Self-contained: a file here imports only its own files (by relative path) and npm packages — never `@/…` or app code
  (`scripts/check-ds-self-contained.mjs`). A test that needs app or API files lives next to that code in the app.
  `apps/web/src/design-system` must not come back (`scripts/check-ds-moved.mjs`).
- Compose existing primitives, components and patterns first. Missing a control or pattern? Add it here, export it
  from its barrel, add a catalog entry and a `src/CHANGELOG.md` line, use it from the feature, and append the gap to
  `.claude/DS-GAPS.md` (append-only).
- CSS: never restyle a shared control from feature CSS. Semantic `--nds-*` tokens only; no raw hex, no numbered ramps
  (`node packages/ui/src/tools/token-guard.mjs`). `src/styles/tokens.css` and `src/styles/tokens-global.css` are
  generated by `npm run tokens:gen` from `src/tokens/*.ts`; never hand-edit them (`npm run tokens:check`).

## Grid
- Import `ag-grid-*` only inside `src/grid/` (`scripts/check-ag-grid-import-boundary.mjs`).
- A grid feature needs its module in `src/grid/modules.ts`, or it silently does nothing in production
  (`npm run grid:modules`).
- A custom cell editor must call `props.onValueChange`; a ref `getValue` is never read. See
  `src/grid/editors/SelectPanelEditor.tsx`.

## Tests
- `cd packages/ui && npx vitest run` (or `npm run test -w @nexus/ui`). Vitest collects only `src/**/*.vitest.test.ts`.
  The environment is Node with no jsdom: test logic, not rendering.
- The web type-checks every file here: `NODE_OPTIONS=--max-old-space-size=12288 npm run typecheck -w @nexus/web`.
